# Nayan Engineering Portfolio — Video Production Brief

**Target:** 40 seconds, 16:9, 1080p  
**Visual direction:** Editorial Swiss / architecture-inspired portfolio design: warm ivory canvas, high-contrast black serif titles, fine hairline rules, small vermilion monospaced labels, restrained grid layouts, compact project metadata. Use real repository screenshots and screen recordings; no generic robot imagery, fake dashboards, fabricated metrics or invented testimonials.

## Creative direction

Show the real static portfolio layout and approved project images only. Demonstrate the project gallery and browser-side calculators with clearly labeled sample inputs. Do not present illustrative placeholder projects as verified client work or imply the calculators replace engineering design or professional review.

## Shot list

0–5s: ivory editorial title. 5–15s: homepage and professional profile. 15–25s: project gallery with approved imagery. 25–33s: engineering calculator with sample inputs and estimate caveat. 33–40s: content architecture and live portfolio URL.

## Voiceover draft

A calm architectural portfolio for civil engineering work, combining project presentation with preliminary browser-based calculators.

## Production checklist

- Capture the current app from the repository; do not invent screens.
- Blur or exclude private data, credentials, tokens and personal information.
- Use only assets the repository owner has permission to publish.
- Verify all calculators, APIs and integrations before showing outputs.
- End with the repository name and a short GitHub URL.
- Export MP4 (H.264), 1920×1080, 24 or 30 fps, with readable captions.

## Generation prompt

Create a 40 seconds 16:9 1080p editorial software-project showcase for “Nayan Engineering Portfolio”. Follow a warm ivory, black serif and vermilion monospaced Swiss portfolio aesthetic with precise grid alignment, thin rules, subtle transitions and clean screen-recording inserts. Use authentic project screenshots and the shot list above. Keep typography crisp and restrained. Do not fabricate UI, metrics, user data, client work or product capabilities. Avoid generic AI robots and neon sci-fi visuals. Finish on a quiet title card with the project name and GitHub repository.
