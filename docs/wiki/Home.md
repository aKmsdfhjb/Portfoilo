# Nayan Engineering Portfolio — Project Wiki

A static React and Vite portfolio for civil engineering work, with project summaries and browser-side engineering calculators. Content is edited in `src/content/site.json`.

## Quick start

Run `npm ci`, `npm run dev` and `npm run build`. Edit verified content in `src/content/site.json` and use approved images only.

## Scope and limitations

This guide describes the current repository. A static build does not automatically provide a backend, authentication service, database or third-party integration. Verify each service in its deployment environment.

Keep credentials and private data out of public commits.
